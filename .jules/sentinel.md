## 2023-11-20 - Insecure Random Number Generation for 2FA Backup Codes
**Vulnerability:** The codebase was using `Math.random()` to generate backup codes for two-factor authentication (2FA). `Math.random()` is not a cryptographically secure pseudo-random number generator (CSPRNG), making the generated backup codes potentially predictable and weakening the security of the 2FA system.
**Learning:** Security-sensitive values, such as authentication tokens, passwords, and backup codes, must always be generated using cryptographically secure methods to prevent prediction attacks. Even seemingly benign uses of random numbers need to be carefully evaluated for security implications if they are related to access control.
**Prevention:** Always use Node.js's built-in `crypto` module (e.g., `crypto.randomInt()`, `crypto.randomBytes()`) or equivalent secure libraries when generating random values for security purposes. Enforce linting rules that flag the use of `Math.random()` in contexts related to cryptography or security.
